# Infinite Irrigation System

Project Zomboid Build 42 mod that combines configurable crop automation, infinite clean water, whole-building water supply, and native electrical power in one placeable pipe system.

Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3548529064

## Features

- Configurable irrigation ranges from 1x1 to 15x15
- Independent irrigation, auto-plowing, crop care, and fertilization switches
- Optional automatic sowing and harvesting with per-crop stock targets
- Infinite clean water for drinking, filling containers, plumbing, and whole-building fixtures
- Native generator-compatible electrical power without fuel, noise, or fumes
- Batched, low-frequency maintenance designed for large farms and multiplayer servers
- English, Simplified Chinese, and Russian localization

## Repository layout

- `Contents/mods/WaterPipes-IrrigationSystems` — Build 42 mod source and assets
- `test_*.lua` — regression tests
- `tools` — asset build helpers
- `release.sh` — generates the local Steam Workshop release directory
- `publish-macos.sh` — validates and uploads the generated release with SteamCMD on macOS
- `workshop*.txt` — English, Simplified Chinese, and Russian Workshop descriptions

## Development install

Copy or link `Contents/mods/WaterPipes-IrrigationSystems` into a Project Zomboid Workshop content tree, then enable `[B42] Infinite Irrigation Pipes` in the game.

The development `mod.info` intentionally uses the ID `InfiniteIrrigationPipes-dev`. The release script changes it to the public Workshop ID `InfiniteIrrigationPipes` only in the generated release directory.

## Release boundary

The development tree is the source of truth. Steam Workshop content must be generated by `release.sh`; do not publish the development directory directly.
